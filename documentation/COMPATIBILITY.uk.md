# Сумісність
[English](COMPATIBILITY.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/+tUZNEgY3aUk4MGIy)

CodeCart зберігає MVC-L route, Events та OCMOD інтеграцію OpenCart/ocStore 3.x. Для наявних розширень використовуйте PHP 8.1–8.3 як ціль сумісності. Ядро також підтримує PHP 8.4/8.5 і має CI-перевірки на цих версіях; окремі модулі, комерційні теми та ionCube-пакети мають власні вимоги.

Є runtime-покриття оновлень ocStore 3.0.4.1, OpenCart 3.0.5.1 та ocStore 3.0.5.0-Beta. Перед публікацією перевірте точну конфігурацію магазину на тестовій копії: framework-тести та міграції не підтверджують усі розширення, реальні платіжні API або UI сторонніх тем. Перед змінами створіть резервну копію файлів сайту та БД.

Чисте встановлення активує лише CodeCart Theme. Оновлення зберігає активну тему кожного магазину, конфігурацію, власні зображення та постійне сховище. Після оновлення перевірте діагностику модифікаторів.
