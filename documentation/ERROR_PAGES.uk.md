# Сторінки помилок
[English](ERROR_PAGES.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/+tUZNEgY3aUk4MGIy)

Комплектні шаблони вітрини CodeCart/default містять адаптивні сторінки 404 та обслуговування англійською, українською й російською. Відсутня сторінка пропонує головну/пошук, обслуговування — повторну перевірку. Відсутні товари/категорії/виробники/інформаційні сторінки зберігають HTTP 404. Обслуговування повертає HTTP 503 із `Retry-After: 3600`; сторінки помилок не індексуються.

Необроблені винятки програми отримують автономну HTTP 500 сторінку без Twig/БД. Технічні повідомлення й шляхи файлів не потрапляють у публічну відповідь. API/JSON/AJAX отримують JSON, CLI — текст. Причину перевіряйте в технічних логах сервера.

Обробник охоплює помилки, що доходять до програми. Помилки вебсервера/CDN, синтаксичні помилки до реєстрації обробника та вичерпання пам'яті потребують окремого налаштування хостингу. Адміністративна 404 зберігає звичайний вигляд. Перевірте сторонні theme overrides та OCMOD на конкретному магазині. Для аналізу відсутнього контенту використовуйте [Втрачені URL](LOST_URLS.uk.md); журнал типово вимкнений.
