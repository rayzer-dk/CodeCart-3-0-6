# Сторінки помилок

[English](ERROR_PAGES.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/codecartpro)

## Єдина дизайн-система

Вітрина й адміністративна панель CodeCart PRO використовують узгоджений адаптивний інтерфейс сторінок помилок. У комплектних темах CodeCart та default сторінки 404 і технічного обслуговування 503 мають повноширинний дизайн. Помилки 404 та 403 в адмініструванні використовують ту саму систему всередині звичайної верхньої панелі й бічного меню. Сторінка 500 відображається автономно.

За замовчуванням усі сторінки помилок відображаються українською, навіть якщо старий магазин налаштовано російською або браузер передає іншу мову. Це основна мова сторінок помилок, а не резервна. Російська й англійська використовуються лише після явного вибору користувачем, у мовному URL або за збереженим особистим вибором адміністратора. Це правило діє також для автономної помилки HTTP 500.

Спільні компоненти й кольорові змінні розміщені у `catalog/view/theme/codecart/stylesheet/error-page.css`: синій акцент 404, бурштиновий 403, кораловий 500, бірюзовий 503. Передбачено адаптивну типографіку, ілюстрацію коду помилки, чіткі кнопки, доступний фокус, світлу й темну теми та режим зі зменшеною анімацією. Адміністративний файл `admin/view/stylesheet/codecart-error-page.css` повторно використовує спільний стиль. Зовнішні шрифти, зображення й JavaScript для сторінок помилок не потрібні.

На сторінці 404 є дії повернення до магазину й пошуку, на 503 — повторна перевірка. З адміністративної помилки можна перейти до панелі керування зі звичайним токеном сесії. Повідомлення і дії локалізовані українською, російською та англійською мовами. Декоративний код помилки прихований від програм екранного читання.

## HTTP-статуси і захист

Відсутні товари, категорії, виробники та інформаційні сторінки повертають HTTP 404 і `noindex,follow`. Технічне обслуговування повертає HTTP 503 із `Retry-After: 3600` і `noindex,nofollow`. Адміністративні помилки повертають HTTP 404 або 403 і `noindex,nofollow`.

Автономна сторінка HTTP 500 формується в `system/helper/error_page.php` без Twig, БД, шапки теми, JavaScript і зовнішніх ресурсів. CSS вбудований локально, є резервний стиль і обмежувальна Content Security Policy. Технічні винятки, SQL і шляхи файлів не показуються відвідувачам. API/AJAX продовжує повертати JSON, CLI — текст.

Обробник діє тільки для помилок, які дійшли до PHP. Помилки вебсервера, проксі, CDN, надраннього завантаження та вичерпання пам’яті потребують окремого налаштування хостингу.

Перевірка: `php tools/qa_error_pages.php` і GitHub Actions **CodeCart Error Page Design QA**. Після розгортання потрібна візуальна перевірка на комп’ютері та телефоні. Сторонні шаблони можуть перевизначати комплектні сторінки. Відсутній контент можна переглянути у [Втрачених URL](LOST_URLS.uk.md); журнал типово вимкнено.
