# CodeCart Build 2.0.1: страницы ошибок

Статус: ready after fixes для описанного покрытия. Перед установкой или обновлением обязательно создать полный backup файлов и БД.

## Изменения

Обе встроенные темы (codecart/default) получили единый адаптивный дизайн 404 и 503. На 404 доступны переход на главную и поиск. На 503 — повторная проверка магазина. Стили изолированы классом ccp-error и подключаются только контроллерами ошибок/обслуживания. Поддержаны светлая и тёмная тема, en-gb/ru-ru/uk-ua.

Отсутствующие товар, категория, производитель и информационная страница также используют этот вид. Ответы сохраняют HTTP 404; страницы обслуживания — HTTP 503 и Retry-After: 3600. Страницы не индексируются.

Обработчик необработанных исключений framework выводит автономную HTML-страницу 500 без Twig и БД. Техническое сообщение и путь к файлу не выводятся в публичном ответе даже при error_display. API-маршруты, запросы с Accept: application/json и XMLHttpRequest получают JSON с HTTP 500. Для CLI сохранён текстовый ответ. Штатное техническое логирование сохранено.

## Проверка

- Автономный renderer: переводы, резервный язык, отказ от javascript/protocol-relative/некорректных URL и URL с секретными query-параметрами.
- HTTP: общая 404 и четыре типа отсутствующих сущностей; 503 с Retry-After; 500 на трёх языках; AJAX/API JSON; отсутствие секретного текста исключения в ответе.
- Браузер: светлый/тёмный 404, тёмный 503, автономный 500, экран 390 px без горизонтального переполнения; кнопка поиска открывает product/search; контраст основного действия исправлен и проверен.
- Дополнительно воспроизведено и устранено переполнение 404 с двумя боковыми колонками: на 768 px карточка 343 px и scrollWidth 343 px; на ширине около 1024 px — 453/453 px.
- Все 630 Twig-шаблонов разбираются без ошибок.
- Release gate PASSED на PHP 8.1.34, 8.2.33 и 8.3.33: 2023 PHP-файла, переводы, BOM, синхронизация CSS и регрессия автономного renderer/сессий. Все 404 хеша integrity manifest повторно сверены, расхождений нет. Независимое ревью после исправления адаптивности существенных замечаний не нашло.

## Ограничения

Это оформление ошибок, дошедших до приложения. Ошибки веб-сервера/CDN, синтаксическая ошибка до регистрации обработчика и исчерпание памяти не покрыты этим renderer. Для них нужны отдельные настройки хостинга. Административная 404 сохраняет штатный вид админки. Сторонние theme overrides в БД и установленные OCMOD необходимо проверить на конкретном магазине.

Журнал потерянных URL и ручные редиректы не включены в эту сборку: состав функции находится на согласовании. Никакие новые таблицы или сбор трафика для неё не добавлены.
