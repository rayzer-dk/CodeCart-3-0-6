# Official CodeCart source and releases
[Українська](GITHUB.uk.md) · [All guides](README.md) · [Community](https://t.me/codecartpro)

**Official public repository:** [CodeCartPro/CodeCartPro-3.0.6.0](https://github.com/CodeCartPro/CodeCartPro-3.0.6.0). This is the canonical destination for releases, downloadable production archives and public documentation. The project owner uploads finished releases and documentation manually.

A GitHub source ZIP is not an installation-ready archive. To install CodeCart, use the reviewed release package, including required Composer dependencies; back up your website and database before installing or upgrading.

If developing extensions or making improvements, check the exact OpenCart/ocStore version and run PHP syntax, integration, security, source integrity and regression checks. Changes to the development source do not automatically publish or replace files in the official public repository.
