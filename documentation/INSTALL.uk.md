# Встановлення — Build 2.0.4

[English](INSTALL.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/+tUZNEgY3aUk4MGIy)

**Перед встановленням створіть і перевірте повну резервну копію сайту та БД.** Для наявного магазину використовуйте [UPDATE](UPGRADE.uk.md); чисте встановлення потребує порожніх БД і кореня сайту.

## Вимоги

Використовуйте PHP 8.1–8.3 для широкої сумісності розширень та MySQL/MariaDB. Ядро також підтримує PHP 8.4/8.5; кожну тему/модуль перевіряйте окремо. Інсталятор перевіряє розширення, TLS і доступність запису конфігурації/сховища. Потрібні драйвер MySQL (`mysqli` або `pdo_mysql`), GD, cURL, OpenSSL, zlib, ZIP, SimpleXML, mbstring, DOM, XMLWriter, fileinfo, JSON, hash та iconv. Усуньте всі блокувальні зауваження.

На робочому сайті використовуйте HTTPS. Apache потребує комплектного `.htaccess` і rewriting; nginx — [правил сервера](NGINX.uk.md). За можливості розмістіть постійне сховище поза коренем сайту й надайте PHP право запису в runtime-каталоги. Не встановлюйте `777` для всього сайту.

## Порядок дій

1. Отримайте production ZIP із залежностями `vendor`. Вихідний ZIP із GitHub потребує підготовки Composer.
2. Створіть порожню БД та користувача БД із правами встановлення. Розпакуйте пакет локально.
3. Завантажте лише вміст `upload/`, включно з прихованим `.htaccess`, у корінь сайту. Документацію, інструменти та службові файли зберігайте поза ним.
4. Відкрийте `/install/`, перевірте середовище та введіть дані БД й адміністратора. Входьте за вибраним **ім'ям користувача**, не email.
5. Перевірте вітрину та адмінку. Оновіть **Розширення → Модифікатори**, налаштуйте URL, мову, валюту, пошту, доставку й оплату та перевірте повне оформлення замовлення.
6. Після перевірки видаліть `/install/`. Переконайтеся, що конфігурацію й сховище неможливо завантажити через браузер.

Під час чистого встановлення реєструється й активується лише CodeCart Theme. Файли `default` є резервом сумісності, а не другою встановленою темою. Логотип/favicon змінюються в налаштуваннях; оновлення зберігає власні зображення магазину.

Налаштуйте [Планувальник](SCHEDULER.uk.md) для фонових завдань. Журнал втрачених URL залишається вимкненим до явного ввімкнення.

Підтримка: [support@codecartpro.com](mailto:support@codecartpro.com) · [Спільнота CodeCart PRO](https://t.me/+tUZNEgY3aUk4MGIy)

Штатні `.htaccess` і `robots.txt` не прив’язані до домену. Додавайте лише URL карт сайту, які існують у вашому магазині. Збережіть захист WAF; уникайте загальної заборони обходу `route=`, річного immutable-кешування CSS/JS без версії, жорстко заданих маршрутів карт сторонніх модулів та несумісних із PHP-FPM директив `php_value`. Власні HTTP-сторінки помилок мають існувати; застосунок уже містить сторінки 404/500.
