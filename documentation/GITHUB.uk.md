# Офіційний GitHub CodeCart
[English](GITHUB.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/codecartpro)

**Офіційний публічний репозиторій:** [CodeCartPro/CodeCartPro-3.0.6.0](https://github.com/CodeCartPro/CodeCartPro-3.0.6.0). Тут розміщуються готові релізи, повні інсталяційні архіви та публічна документація. Власник проєкту завантажує готові архіви та документацію вручну.

ZIP із вихідним кодом GitHub не завжди є готовим інсталяційним пакетом. Для встановлення використовуйте перевірений реліз з усіма необхідними залежностями Composer. Перед встановленням або оновленням створіть резервні копії файлів сайту та бази даних.

Перед змінами перевіряйте сумісність із потрібною версією OpenCart/ocStore, безпеку, PHP-синтаксис і регресії. Оновлення вихідного коду в середовищі розробки не публікує файли в офіційному репозиторії автоматично.
