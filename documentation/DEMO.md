Explore the [storefront](https://test.codecartpro.com/) and [administration](https://test.codecartpro.com/admin/).

Public demonstration login: **Demo**. Password: **1234567890**.

This shared test store presents products, articles and example commerce records. The demo password belongs only to this demonstration account; choose an individual strong administrator password for your own installation. Demo records do not represent real transactions.

The public demo account can browse the administration but cannot save changes. Example customers, orders and abandoned carts belong only in the demonstration database; the production installer does not create fictional sales. Back up files and the database before importing demonstration data into the dedicated test store.

In Marketing → Mail, select **New template** and click **Open** to import a UTF-8 `.html` or `.htm` file up to 1 MB. Import fills the editor without saving or sending. Scripts and unsafe HTML are removed. Review the message, enter its subject and name, then save. With a saved template selected, Open loads that template from the database.

**Awaiting stock** lists requests submitted by customers on unavailable products. It is not a manual mailing list. **Abandoned carts** shows carts inactive for more than one hour and updated within the last seven days; demonstration carts consequently expire from this report.
