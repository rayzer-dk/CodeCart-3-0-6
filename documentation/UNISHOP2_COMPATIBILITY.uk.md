# Сумісність UniShop2
[English](UNISHOP2_COMPATIBILITY.md) · [Усі інструкції](README.uk.md) · [Спільнота](https://t.me/+tUZNEgY3aUk4MGIy)

**Перед встановленням/оновленням теми створіть резервну копію сайту/БД.** За власними вимогами UniShop2 3.6.6.0 потребує PHP 8.1–8.3 та сумісного ionCube Loader. Підтримка PHP 8.4/8.5 ядром CodeCart не розширює вимоги теми.

На тестовій копії дотримуйтеся оригінальної інструкції теми: встановіть `unishop2_fix.ocmod.zip`, оновіть модифікатори, встановіть `unishop2_v3.6.6.0.ocmod.zip`, установіть/увімкніть/налаштуйте тему й знову оновіть модифікатори. Перед активацією на робочому сайті перевірте діагностику, опції товару, галерею, категорії, меню, кошик та оформлення.

CodeCart надає розширення шляхів інсталятора, поведінку Twig loaders та адаптер старих контрактів меню/категорій/опцій товару/банерів. Адаптер працює лише за `config_theme=unishop2`, наявних налаштувань і невимкненої теми. Самі файли неактивної теми його не вмикають. Дивіться [інструкцію розробника](COMPATIBILITY_FRAMEWORK.uk.md).

Не встановлюйте необов'язковий `webp_img.ocmod.zip`: CodeCart має власну обробку зображень. `fix_og.ocmod.zip` не потрібен, оскільки CodeCart забезпечує OpenGraph. `unishop2_tool.ocmod.zip` — необов'язковий demo/import-інструмент. Типовий SQL-режим відповідає сумісності OpenCart; strict mode вмикайте лише після перевірки розширень.

Перевірені framework/OCMOD-контракти та окремий HTTP-сценарій відсутньої новини з оригінальними controller/model, мінімальною порожньою схемою й CodeCart Theme. Це не підтверджує повний UI комерційної UniShop2 або всі комбінації модулів. Вихідний код сторонньої теми не входить у CodeCart.
