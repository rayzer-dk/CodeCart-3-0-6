# CodeCart Build 2.1.1: аудит и исправления

Дата: 2026-10-21. Исправления c81d071bf29c7b014a34410116ddc959fcb38e20 и e85a5975ac729136302b88d03dff00ac4197f971 отправлены в main поверх 86588bf; оба удалённых SHA проверены. Статус: ready after fixes в пределах описанной проверки; безусловная готовность любого рабочего магазина этим аудитом не устанавливается.

## Выполнено

- Закрыт внешний доступ к внутренним cron routes с сохранением штатного авторизованного gateway и CLI.
- HTML обрабатывается штатным парсером с проверкой реальных растровых data URI, включая WebP/AVIF. Сохранены контракты хранения и повторного открытия содержимого.
- Усилены постоянные лимиты TOTP, конкурентный лимит источника, одноразовые recovery codes и защита от replay. Ошибки отправки подтверждения устройств блокируют авторизацию.
- Сохранены корзина при ротации сессии и изоляция входа администратора. Исправлены обработка фоновых заданий, stock notification и производные изображения.
- Согласован выбор главной категории для двух схем ocStore/OpenCart и SEO cache. Обновление сохраняет существующий контент продавца.
- Миграция расширяет восемь IP-полей до 45 символов и shipping_company до 60 без сужения более широких полей. Маркер завершения публикуется после успешных шагов и журнала, чтобы сбой допускал повтор.
- Синхронизированы Build 2.1.1, документация, бонусные архивы и воспроизводимые сборщики. Существующие upstream изменения времени установки сохранены.

## Незакрытые ограничения

- История PHPStan: c81 имел FAIL, admin 264/catalog 366 диагностик; сравнение с прежними 267/348 ограничено разным списком целей. Причины исправлены в e85a597 точными контрактами; результат затронутого scope теперь PASS. Старые журналы и отрицательный fixture сохранены, baseline/новые подавления не добавлялись. PHPCS и Source Guard прошли; Rector dry-run c81 прошёл.
- Итоговый прогон 20 октября был прерван изменением двух файлов и имеет статус INCOMPLETE_SOURCE_CHANGED. Сбой sandbox fixtures отдельно воспроизведён и устранён только выбором окружения, без ослабления assertions.
- Внешние SMTP и платёжные API, лицензированная коммерческая UniShop2, MySQL, большие production таблицы и DDL блокировки на них, автоматический cron реального хостинга не проверены.
- Локальная HTTP проверка использовала PHP server и QA router; это не доказательство поведения Apache/Nginx реального хостинга. Локальная оценка скорости не является production load test.
- До установки или обновления обязательна полная резервная копия сайта и БД. На рабочие магазины изменения не развёртывались.
