ENGLISH
Create and verify a complete website/database backup first.
Use the production ZIP with vendor dependencies, not GitHub's source Download ZIP.
Upload ONLY the CONTENTS of upload/ to the store web root.
Keep documentation/, tools/ and repository metadata outside the public website.
New store: open /install/. Administrator login is the chosen username, not email.
Existing store: preserve config.php, admin/config.php, merchant images and actual persistent storage. Open /install/, sign in with an authorized administrator and use UPDATE. Never import install/opencart.sql into an existing store.
After installation/update: refresh Modifications, verify the store, remove /install/.
Full instructions: README.md and documentation/README.md.
