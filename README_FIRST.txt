CodeCart 3.0.6

E-commerce CMS based on OpenCart/ocStore 3.x. Developer: CodeCart PRO. License: GPL-3.0.

ENGLISH
Create and verify a complete website/database backup before installation or update.
Use the full Production ZIP with Composer dependencies, not the GitHub source ZIP.
Upload ONLY the CONTENTS of upload/ to the web root, never repository metadata or tools.
New store: follow documentation/INSTALL.md and finish the installer.
Existing store: follow documentation/UPGRADE.md. Preserve config.php, admin/config.php, merchant images, database and persistent storage. Never import install/opencart.sql into a live store.
After changing the core: refresh Modifications, purge Twig/theme cache, verify product pages and storefront URLs; remove install/ after a completed fresh installation.
Detailed platform description: README.md. Source publishing: documentation/GITHUB.md.

УКРАЇНСЬКА
Створіть і перевірте резервну копію файлів магазину й бази даних перед встановленням або оновленням.
Використовуйте повний Production ZIP із залежностями Composer, а не архів вихідного коду GitHub.
У корінь сайту завантажуйте ЛИШЕ ВМІСТ папки upload/, без службових файлів репозиторію.
Новий магазин: інструкція documentation/INSTALL.uk.md.
Чинний магазин: документація documentation/UPGRADE.uk.md. Збережіть config.php, admin/config.php, зображення, базу даних і постійне сховище. Не імпортуйте install/opencart.sql у робочу базу.
Після оновлення: оновіть модифікатори, очистьте кеш Twig/теми, перевірте сторінки товарів і мовні URL. Після чистого встановлення видаліть install/.
Повний опис платформи: README.uk.md. GitHub: documentation/GITHUB.uk.md.
