# Security Policy

## Supported branch

Security fixes are applied to the current CodeCart 3.0.6 development/release branch.

## Reporting a vulnerability

Do not publish exploitable security details in a public Issue or Discussion.

For a public repository, use GitHub's private Security Advisory reporting flow when available. For a private development repository, contact the repository owner privately.

Include the affected build/version, affected route or component, reproduction steps, impact, and a safe proof of concept when appropriate.

Never include real passwords, API keys, license keys, customer data or production secrets in reports.
