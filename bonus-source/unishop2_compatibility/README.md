# UniShop2 Compatibility PRO 1.0.1

Автор: CodeCart PRO, https://codecartpro.com.

Пакет для CodeCart 3.0.6.0, Build 2.1.0 или новее, и оригинальной UniShop2 3.6.6.0. Для обычного OpenCart и старых сборок CodeCart пакет не предназначен. Сначала обновите CodeCart: нормализация stock-sort OCMOD находится в ядре Build 2.1.0.

Перед установкой, обновлением или удалением обязательно сделайте полную резервную копию файлов сайта и базы данных.

## Установка и обновление

1. Проверьте версию CodeCart и наличие легально приобретенной оригинальной UniShop2 3.6.6.0.
2. Отключите или удалите старый UniShop2 Compatibility PRO 1.0.0 и исключите одновременное использование оригинального и Combined OCMOD одной темы. Должен остаться один основной модификатор UniShop2. Не удаляйте файлы работающей темы.
3. Установите UniShop2_Compatibility_Pro_v1.0.1.ocmod.zip через штатный установщик расширений. Постоянный код модификатора unishop2_compatibility_pro_100 сохранен для обновления.
4. Обновите модификаторы. Проверьте результат обработки, журнал OCMOD, каталог, сортировку по наличию, карточку товара, изменение количества и оформление заказа.

Пакет исправляет прямое чтение отсутствующего qty_switch.type в controller uni_new_data.php. Поиск учитывает пробелы и табуляцию. Настройки и данные магазина не меняются. Нормализация двух известных stock-sort операций оригинальной UniShop2 выполняется ядром при обновлении модификаторов, поэтому не зависит от очередности этого пакета и основного OCMOD. Чужие версии и неизвестные payload ядро не переписывает.

## Удаление и повторная установка

Отключите/удалите этот модификатор, затем обновите модификаторы. Прямое чтение qty_switch.type вернется к оригинальной реализации UniShop2. Изменения штатного адаптера CodeCart остаются частью ядра. Для повторной установки установите пакет и снова обновите модификаторы.

## Границы проверки

Проверки исходников, генерируемого PHP и отдельных операций OCMOD не подтверждают полную работоспособность коммерческой темы. После обновления требуется проверка работающего тестового магазина, включая AJAX, checkout, платежи, доставку и сторонние модули. Пакет не содержит коммерческих исходников UniShop2, не меняет их лицензирование и не выполняет активацию темы.
